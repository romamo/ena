# Συνέντευξη (6–7 λεπτά)

Greek version of [guide.md](guide.md). Machine translation: have a native speaker check it before use.

## Ερωτήσεις

1. Πόσα τιμολόγια προμηθευτών πληρώνετε τον μήνα και πώς τα πληρώνετε; (ποια τράπεζα, ποια εφαρμογή)
2. Ποιος κρατά τα λογιστικά σας και πόσο σας κοστίζει, σε χρήματα και σε δικές σας ώρες;
3. Για τι άλλο πληρώνετε για να λειτουργεί η επιχείρηση, εκτός από την ίδια τη δουλειά; (ιστοσελίδα, μέσα κοινωνικής δικτύωσης, εφαρμογή κρατήσεων, καθαρισμός, άλλοι συνεργάτες) Πόσα τον μήνα για το καθένα;
4. Πόσες ώρες την εβδομάδα αφιερώνετε εσείς σε μηνύματα με πελάτες, παραγγελίες αναλωσίμων, τιμολόγια και πληρωμές;
5. Πότε ήταν η τελευταία φορά που τα χρήματα δεν έφταναν; Τι κάνατε;
6. Έχετε δανειστεί ποτέ για την επιχείρηση ή σας έχουν αρνηθεί; (επιχειρηματικό δάνειο, παρατράβηγμα)
7. Μέχρι ποιο ποσό θα αφήνατε έναν βοηθό να πληρώνει τους προμηθευτές σας χωρίς να σας ρωτά;
8. Φανταστείτε έναν βοηθό που παραλαμβάνει τα τιμολόγια των προμηθευτών σας, κρατά τα λογιστικά, σας δείχνει τα διαθέσιμα χρήματα για τον επόμενο μήνα, πληρώνει μέσα στο όριό σας και σας προτείνει χρηματοδότηση από την τράπεζα όταν τα χρήματα δεν φτάνουν. Για ποιο μέρος θα πληρώνατε και πόσο τον μήνα;

## Κανόνες

- Ρωτάμε για όσα έχουν ήδη συμβεί («την τελευταία φορά…»), ποτέ «θα χρησιμοποιούσατε…»
- Περιγράφουμε την ιδέα μόνο στην τελευταία ερώτηση
- Σημειώνουμε έναν αριθμό και μια ακριβή φράση σε κάθε απάντηση
