Backup: show it for technical questions. “Three inputs, one server, one door for money. Jinius and JCC come in, the owner talks to Ena in the chat and the dashboard. Every payment goes through the gate, which checks the limit and writes the receipt. The rules compute the books, the forecast and the offers. The AI agent only calls tools: it never sets an amount, and its process never holds a bank or Jinius secret.”
